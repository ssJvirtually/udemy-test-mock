# MockMaster — Udemy-Style AI Practice Exam Platform

> A client-side exam practice platform designed to match the **Udemy practice test UI/UX**, engineered specifically for seamless hosting on **GitHub Pages** with zero backend required.

Generate high-yield mock exams with **ChatGPT**, **Claude**, **Gemini**, or **DeepSeek** in JSON format, upload them, and practice in an authentic Udemy test simulator.

---

## 🌟 Key Features

### 1. Authentic Udemy Practice Test Interface
- **Udemy Brand Identity**: Signature Udemy purple accents (`#a435f0`), dark slate typography (`#2d2f31`), clean borders, and cards.
- **Timed Exam & Practice Modes**:
  - **Strict Exam Mode**: Countdown timer, pause modal, submission review, and final report card.
  - **Practice Mode**: Instant "Check Answer" button on every question for immediate learning.
- **Question Palette & Navigator Drawer**:
  - Filter questions by **All**, **Answered**, **Unanswered**, and **Marked for Review**.
  - Jump to any question instantly.
- **Mark for Review**: Flag tricky questions to revisit before final submission.
- **Scenario Questions & Code Snippets**: Full markdown rendering with dark syntax-highlighted code blocks for technical certifications.
- **Single & Multi-Select**: Supports single choice (radio) and "Select TWO / THREE" questions.

### 2. Comprehensive Results & Performance Analytics
- **Udemy Report Card**: Big score percentage, pass/fail status, passing threshold, and celebration confetti on pass!
- **Domain / Knowledge Area Breakdown**: Progress bars for each syllabus domain showing individual domain scores.
- **Question-by-Question Review**:
  - Deep-dive into what you chose vs the correct answers.
  - Comprehensive overall explanation.
  - Option-by-option rationale breakdown (*"Why A is right"*, *"Why B is wrong"*).
  - Official documentation & reference links.
- **Smart Retake Missed Questions Only**: Retake just the questions you got wrong or skipped!

### 3. Built-In LLM Prompt Generator & JSON Schema
- **Home Page Prompt Builder**: Prominently featured on the landing page with 1-click **"Copy Full Prompt"**.
- **Certification Presets**: AWS Solutions Architect (SAA-C03), Modern React Architecture, Python Backend, PMP, and Custom Topics.
- **Customizable Parameters**: Adjust question count (5 to 65), difficulty level, code snippets, and multi-choice percentage.
- **JSON Validator & Sanitizer**:
  - Drag-and-drop or paste raw JSON.
  - Automatically strips markdown code fences (` ```json `).
  - Smart tolerance for 0-based and 1-based indices or letter answers (A/B/C/D).

### 4. 100% Client-Side & Private
- Hosted statically on **GitHub Pages**.
- All uploaded exams, attempts, and scores are stored in your browser's `localStorage`.
- Zero tracking, zero server costs.

## 🚀 How to Deploy to GitHub Pages

### Method A: Automated Deployment with GitHub Actions (Recommended)
This repository already includes `.github/workflows/deploy.yml`.

1. Create a new repository on GitHub (e.g. `udemy-mock-exam`).
2. Push this project to GitHub:
   ```bash
   git add .
   git commit -m "Initial commit of MockMaster platform"
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git branch -M main
   git push -u origin main
   ```
3. In your GitHub repository:
   - Go to **Settings** → **Pages**.
   - Under **Build and deployment** → **Source**, select **GitHub Actions**.
4. The workflow will automatically trigger, build the site, and publish it to:
   ```
   https://<your-username>.github.io/<your-repo-name>/
   ```

### Method B: Manual Deployment with `gh-pages`
If you prefer deploying directly from your terminal:
```bash
npm run deploy
```

## 🤖 How to Generate Questions Using LLMs

1. Open the platform's home page and navigate to the **LLM Prompt Generator** section.
2. Select your topic or certification (or enter a custom one).
3. Click **Copy Full Prompt**.
4. Paste it into **ChatGPT (GPT-4o)**, **Claude 3.5 Sonnet**, **Gemini 2.0 / 1.5 Pro**, or **DeepSeek-R1 / V3**.
5. Copy the JSON generated by the model.
6. In MockMaster, click **Upload JSON**, paste the JSON, and click **Start Practice Test**!

## 📋 JSON Schema Specification

```json
{
  "title": "AWS Solutions Architect Practice Exam",
  "description": "High-yield scenario questions modeled after the SAA-C03 certification.",
  "durationMinutes": 45,
  "passingScore": 72,
  "category": "Cloud Computing",
  "domains": [
    "Domain 1: Design Secure Architectures",
    "Domain 2: Design Resilient Architectures"
  ],
  "questions": [
    {
      "id": 1,
      "domain": "Domain 1: Design Secure Architectures",
      "difficulty": "Intermediate",
      "type": "single",
      "question": "Which architecture provides the most cost-effective auto-scaling capability with zero downtime?",
      "codeSnippet": "",
      "options": [
        "Attach an Auto Scaling group with Target Tracking.",
        "Manually increase EC2 instance sizes.",
        "Single EC2 instance with Multi-AZ.",
        "Amazon S3 static hosting."
      ],
      "correctAnswer": 0,
      "explanation": "Target tracking automatically adjusts capacity to maintain target metric utilization.",
      "optionRationales": {
        "A": "Correct: Scales dynamically with demand.",
        "B": "Incorrect: Manual scaling lacks agility.",
        "C": "Incorrect: Single instance is a single point of failure.",
        "D": "Incorrect: Cannot run server-side app."
      },
      "referenceUrl": "https://docs.aws.amazon.com/autoscaling/"
    }
  ]
}
```

### Schema Field Rules
| Property | Type | Description |
| :--- | :--- | :--- |
| `title` | `string` | Exam title |
| `durationMinutes`| `number` | Allowed time in minutes (default: question count × 1.5) |
| `passingScore` | `number` | Passing percentage (default: `72`) |
| `domains` | `string[]` | Knowledge areas for domain report breakdown |
| `questions[].type` | `"single"` \| `"multiple"` | Single choice or multi-select |
| `questions[].correctAnswer` | `number` \| `number[]` | 0-based index (e.g. `0` for A, or `[0, 2]` for A and C) |
| `questions[].explanation` | `string` | Comprehensive explanation of the correct solution |
| `questions[].optionRationales` | `object` | Optional breakdown for each option (`{"A": "...", "B": "..."}`) |
